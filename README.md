# Enc-hub Project

A Python GUI application implementing multiple classical and modern ciphers including Caesar, Monoalphabetic, Playfair, Polyalphabetic, Vigenère, Rail Fence, Row Transposition, DES, and AES. Users can select a cipher and perform encryption or decryption through an interactive interface.

## Features
- Encrypt and decrypt messages using classical ciphers:  
  - Caesar, Monoalphabetic, Playfair, Polyalphabetic, Vigenère, Rail Fence, Row Transposition
- Encrypt and decrypt messages using modern ciphers:  
  - DES, AES
- User-friendly GUI interface for easy interaction
- Select any cipher and choose between encryption or decryption
- Real-time input and output for text messages

## Technologies Used
- **Python 3.x** : Core programming language
- **Tkinter** : GUI development
- **PyCryptodome** : Implementation of DES and AES ciphers
- Object-Oriented Programming (OOP) principles for clean and modular code
